# mngment — Маркетинговое агентство для B2B

Сайт: [mngment.ru](https://mngment.ru/)

## О проекте

Статический сайт маркетингового агентства. Содержит 9 страниц услуг, 19 статей блога, 7 кейсов, 2 калькулятора, страницу контактов и лид-магниты.

## Технологии

- HTML5, CSS3, JavaScript (ванильный)
- GitHub Pages
- Микроразметка Schema.org (JSON-LD)
- Адаптивная вёрстка (mobile-first)

## Структура

- `/services/` — 13 страниц услуг
- `/blog/` — 25 статей + страница-хаб
- `/cases/` — 10 кейсов + страница-хаб
- `/tools/` — 2 калькулятора/теста
- `/contacts/` — контакты + бриф
- `/thank-you/` — страница благодарности
- `/404.html` — страница не найдена
